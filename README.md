# 🌌 Milky Way Theme

ثيم فضائي غريب وصادم لمتاجر سلة 🚀✨  
مشروع مفتوح المصدر، جاهز للتعديل والتوسع.  

## البدء
1. انسخ المستودع:
   ```bash
   git clone https://github.com/username/Milky-Way.git
   ```
2. ادخل المجلد:
   ```bash
   cd Milky-Way
   ```
3. ابدأ التطوير ✨

## المجلدات
- `src/components` : المكونات (أزرار، كروت، إلخ).  
- `src/layouts` : الهياكل العامة للصفحات.  
- `src/pages` : الصفحات (الرئيسية، المنتجات، إلخ).  
- `src/assets` : الصور والستايلات.
